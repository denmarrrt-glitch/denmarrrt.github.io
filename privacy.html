Политика конфиденциальности приложения «Разберёмся»

Дата вступления в силу: 3 ноября 2026 г. Последнее обновление: 3 ноября 2026 г.

Настоящая политика описывает, какие данные собирает и использует приложение «Разберёмся» (далее — «Приложение»), зачем они нужны, где хранятся и как их можно удалить. Приложение создано автором YouTube-канала «Разберёмся» для загрузки видео на собственный канал.

1. Оператор данных

Оператор Приложения — автор YouTube-канала «Разберёмся» (псевдоним: Разберёмся). Все вопросы о данных направляйте на адрес: EMAIL_PLACEHOLDER.

2. Какие данные использует Приложение

Приложение работает с YouTube через YouTube Data API v3 и использует только следующие данные:

  • Данные авторизации (OAuth-токены). После входа в Google-аккаунт канала Google выдаёт токен доступа и токен обновления. Они позволяют Приложению выполнять действия от имени канала.
  • Данные канала. Идентификатор и название канала, которые Приложение получает от YouTube, чтобы убедиться, что загрузка идёт на нужный канал.
  • Контент, который автор выбирает для загрузки. Видеофайл, название, описание, теги, язык, настройки публикации (например, время и приватность), миниатюра. Всё это задаёт сам автор при запуске Приложения.

Приложение запрашивает только следующие права доступа Google: youtube.upload (загрузка видео) и youtube (управление видео и метаданными канала). Приложение не запрашивает доступ к почте, контактам, Google Диску, истории просмотров или другим сервисам Google.

Приложение не запрашивает и не сохраняет пароль Google-аккаунта. Вход выполняется на странице Google, а Приложение получает только токены.

3. Для чего используются данные

Данные используются только для того, чтобы:

  • авторизовать Приложение в YouTube от имени канала автора;
  • загрузить выбранное видео на канал и задать его метаданные и настройки публикации;
  • проверить, что загрузка выполняется на нужный канал.

Данные не используются для рекламы, профилирования, аналитики поведения пользователей или обучения моделей машинного обучения. Приложение не отслеживает действия автора за пределами запуска загрузки.

4. Где хранятся данные

Приложение не имеет собственного сервера и не передаёт данные разработчику или третьим лицам. Все данные хранятся только на компьютере автора в локальных файлах:

  • client_secret.json — учётные данные OAuth-приложения, созданные в Google Cloud Console;
  • token.json — токены доступа и обновления, полученные после авторизации.

Видеофайлы загружаются на YouTube напрямую с компьютера автора. Обработка этих данных осуществляется в соответствии с Политикой конфиденциальности Google и Условиями использования YouTube.

5. Передача данных третьим лицам

Данные не продаются, не передаются и не раскрываются третьим лицам. Единственный получатель данных — YouTube и Google, куда автор загружает видео в рамках своего канала.

6. Соответствие требованиям Google API

Использование информации, полученной через API Google, соответствует Политике пользовательских данных API Google, включая требования об ограниченном использовании (Limited Use). Приложение также соблюдает Условия использования сервисов YouTube API и Политику конфиденциальности Google.

7. Безопасность

Файлы client_secret.json и token.json должны храниться только на компьютере автора и не публиковаться в открытых репозиториях, мессенджерах и облачных папках с общим доступом. Автор самостоятельно отвечает за безопасность своего компьютера и учётной записи Google.

8. Срок хранения и удаление данных

Токены хранятся в файле token.json, пока автор не удалит его вручную. Видео и метаданные хранятся на YouTube по правилам YouTube, автор управляет ими в YouTube Studio.

Чтобы отозвать доступ Приложения к каналу:

  1. откройте страницу управления доступом Google-аккаунта: myaccount.google.com/permissions;
  2. найдите «Разберёмся» и нажмите «Удалить доступ».

После этого удалите файлы token.json и client_secret.json с компьютера. Поскольку Приложение не хранит данные на сервере, других копий данных у оператора нет.

9. Права пользователя

Вы можете в любой момент получить информацию о том, какие данные использует Приложение, попросить их исправить или удалить, а также отозвать доступ способом из раздела 8. Для этого напишите на адрес из раздела 1.

10. Дети

Приложение предназначено только для совершеннолетнего автора канала и не предназначено для детей. Оператор сознательно не собирает данные лиц младше 18 лет.

11. Изменения политики

Если политика изменится, новая версия будет опубликована на этой странице с новой датой вступления в силу. Если изменится набор собираемых данных или способ их обработки, обновление будет отражено здесь до начала такой обработки.
