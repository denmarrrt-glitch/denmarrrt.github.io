Политика конфиденциальности

Дата вступления в силу: 3 ноября 2026 г.

1. Кто отвечает за данные

Приложение «Разберёмся» создано и используется автором YouTube-канала «Разберёмся» (псевдоним: Разберёмся). Контакт для вопросов: EMAIL_PLACEHOLDER.

2. Какие данные использует приложение

Приложение обращается к YouTube Data API через учётные данные OAuth, созданные автором. Оно получает и хранит только:

  • токен доступа и токен обновления, которые Google выдаёт после входа в аккаунт канала;
  • данные канала, необходимые для загрузки: идентификатор канала, название, описание и теги видео, которые задаёт сам автор.

Приложение не запрашивает и не сохраняет пароль Google-аккаунта.

3. Где хранятся данные

Все данные хранятся только на компьютере автора в локальных файлах (client_secret.json и token.json). Приложение не отправляет данные на серверы разработчика и не передаёт их третьим лицам.

4. Как используются данные

Данные используются исключительно для загрузки видео и управления метаданными видео на канале автора. Данные не используются для рекламы, профилирования и обучения моделей.

5. Соответствие требованиям Google

Использование информации, полученной через API Google, соответствует Политике пользовательских данных API Google, включая требования об ограниченном использовании данных. Также применяются Условия использования сервисов YouTube API и Политика конфиденциальности Google.

6. Удаление данных и отзыв доступа

Чтобы удалить доступ приложения, откройте настройки безопасности Google-аккаунта (раздел «Сторонние приложения с доступом к аккаунту»), найдите «Разберёмся» и нажмите «Удалить доступ». После этого удалите файлы token.json и client_secret.json с компьютера.

7. Изменения политики

Если политика изменится, новая версия будет опубликована на этой странице с новой датой вступления в силу.
